Add Sirv as a first-class media source inside Strapi, the leading open-source headless CMS.

Editors browse, search and pick images, videos, 360 spins and Sirv Media Viewers straight from your connected Sirv account, without leaving Strapi. Your files stay on Sirv and are delivered from Sirv's fast, global CDN, then rendered on your frontend with the companion @sirv/react package.

Because assets live on Sirv, you get automatic image optimization, responsive images, dynamic resizing, 360 spins and zoom, all without bloating your Strapi database.

Requirements

  • Strapi v5 (5.x)
  • Node.js 18 or newer
  • A Sirv account. Create one for free if you don't have one.

Installation

1. Install the plugin in your Strapi project:

npm install @sirv/strapi-plugin

2. Enable it in config/plugins.ts (or config/plugins.js):

export default {
  sirv: {
    enabled: true,
  },
};

3. Strapi's admin panel uses a strict Content-Security-Policy that blocks external images. Since Sirv delivers assets from *.sirv.com, allow it in config/middlewares.ts, otherwise thumbnails and previews won't load:

export default [
  'strapi::logger',
  'strapi::errors',
  {
    name: 'strapi::security',
    config: {
      contentSecurityPolicy: {
        useDefaults: true,
        directives: {
          'img-src': ["'self'", 'data:', 'blob:', 'https://*.sirv.com'],
          'media-src': ["'self'", 'data:', 'blob:', 'https://*.sirv.com'],
          'script-src': ["'self'", 'blob:', 'https://scripts.sirv.com'],
        },
      },
    },
  },
  'strapi::cors',
  'strapi::poweredBy',
  'strapi::query',
  'strapi::body',
  'strapi::session',
  'strapi::favicon',
  'strapi::public',
];

4. Rebuild and start Strapi:

npm run develop

A Sirv section now appears under Settings in the admin panel.

Connect your Sirv account

1. In the Strapi admin, open Settings → Sirv → Configuration.

2. Enter your Sirv REST API Client ID and Client secret. You'll find (or create) them in your Sirv account at Settings → API.

3. Click Connect. Your credentials are validated against Sirv, then stored encrypted on the Strapi server. They are never exposed to the browser.

Once connected, the page shows your account and its storage usage. You can disconnect at any time.

Add the Sirv media field

The plugin adds a custom field, Sirv media, that you can add to any content type.

1. In the Content-Type Builder, edit a content type, click Add another field, choose Custom, then Sirv media.

2. Or declare it directly in the content type's schema.json. Use allowedTypes to restrict what can be picked, and multiple for a gallery:

{
  "attributes": {
    "hero": {
      "type": "customField",
      "customField": "plugin::sirv.sirv-media",
      "options": { "allowedTypes": ["image", "video"] }
    },
    "gallery": {
      "type": "customField",
      "customField": "plugin::sirv.sirv-media",
      "options": { "allowedTypes": ["image", "video", "spin", "view"], "multiple": true }
    }
  }
}

Supported asset types are image, video, 360 spin and Sirv Media Viewer.

Pick an asset

When editing content, a Sirv media field shows a Pick from Sirv button. Click it to open the DAM browser: navigate folders, search your account, and filter by type.

Click an asset to preview it. Images show a large preview; spins, viewers and videos render an interactive live preview. From here you can open the original file or open it on my.sirv.com. Click Use this asset to store it in the field.

The picked asset appears in the field with a thumbnail. Its title and description (if set on Sirv) are stored automatically as alt text and caption.

Pick multiple assets (gallery)

For a field with multiple: true, the browser lets you select several assets at once. Tick each asset and click Add to build an ordered gallery. Remove or reorder items in the field afterwards.

Render on your frontend

Each Sirv media value is stored in a shape that the companion @sirv/react package renders directly, no conversion needed. Install it in your frontend (Next.js, Nuxt, Astro, Remix, etc.):

npm install @sirv/react

Fetch your content from Strapi's REST or GraphQL API, then pass the stored value to the matching component:

import { SirvProvider, SirvImage, SirvVideo, SirvSpin, SirvView, SirvMedia, SirvGallery } from '@sirv/react';

export default function Post({ post }) {
  return (
    <SirvProvider>
      {/* Type-specific components */}
      <SirvImage value={post.hero} width={800} />
      <SirvVideo value={post.clip} width={640} />
      <SirvSpin  value={post.spin} width={500} height={500} />
      <SirvView  value={post.viewer} width={640} height={440} />

      {/* Or the polymorphic component - renders the right one automatically */}
      <SirvMedia value={post.hero} width={800} />

      {/* A gallery from a multiple field */}
      <SirvGallery items={post.gallery} />
    </SirvProvider>
  );
}

<SirvImage> emits a responsive srcset and lazy-loads by default; <SirvSpin> and <SirvView> load sirv.js for interactive 360 spins and zoom.

FAQ

Do my files get copied into Strapi?

No. Your files stay on Sirv. The field stores a lightweight reference to the asset, and it is delivered from Sirv's CDN. This keeps your Strapi database small and gives you Sirv's image optimization, responsive images and 360/zoom for free.

Which asset types are supported?

Images, videos, 360 spins and Sirv Media Viewers. You can restrict what a field accepts with the field's allowedTypes option.

Are my Sirv credentials safe?

Yes. Your Client ID and secret are validated and then stored encrypted on the Strapi server. All Sirv API calls are proxied server-side, so credentials are never sent to the browser.

Why aren't thumbnails showing in the admin?

Strapi's admin sets a strict Content-Security-Policy that blocks external images. Add https://*.sirv.com to img-src and media-src (and https://scripts.sirv.com to script-src) in config/middlewares.ts, as shown in the installation steps.
